# Product — foto-esqueleto

A skeleton for small, single-file photo tools for photographers.

- Each tool is ONE HTML file: no install, no account, no server, works offline.
- Photos never leave the device (privacy is a feature, not a setting).
- Built for photographers, not developers: large controls, few options, German UI first.
- The skeleton is proven by two different apps built on it:
  1. **Enfoque** — focus peaking for macro photography (camera or photo).
  2. **Kontaktbogen** — many photos into one printable sheet or postcard.
- Origin: the author's real tools for his orchid photography project ORCHIDACEAE
  (focus checking in the greenhouse, 35-orchid postcard grids).
